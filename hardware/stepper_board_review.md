# 步进电机控制板 —— 设计复核与修改清单

> 依据：`Netlist_Schematic1_2026-10-26.net`（PROTEL 2.0）
> 对象：ESP32-S3-WROOM-1-N16R8 + 2×LY2834E（双极步进）+ OV2640 + TP4054 + TPS63002/63031
> 用途：U4 / U6 为两个双极步进电机的四线端子（A+ / A- / B+ / B-）

---

## 0. 先给结论

| 级别 | 数量 | 说明 |
|---|---|---|
| 致命（板子不上电） | 2 | U7/U8 的 VIN/VOUT 接反且 EN 自锁；D1 反接 |
| 严重（能上电也跑不起来） | 4 | 电机 IO 撞 PSRAM；电机供电能力不足；电感饱和电流不够；电机与充电器抢 5V |
| 中等（能跑但不稳/易坏） | 10 | EN 无 RC、IO0 无上拉、USB 反插不识别、充电电流过大、无保护等 |

**按现状：插 USB 不亮，插电池也不亮。**

---

## 1. 目标电源树（改完应该是这样）

方案 A（推荐，最简）：删掉 U8，5V 只来自 USB，电机直接吃电池。

```
USB-C VBUS ──D1(A→K)──► +5V ──► U9 TP4054 ──► VCC(电池)
                                                │
                          ┌─────────────────────┼──────────────────┐
                          │                     │                  │
                     U2/U5 VM             U7 TPS63031          H1 电池
                   (步进 3.0~4.2V)      VIN=VCC → VOUT=3.3V    (1S)
                                              │
                                        MCU / 相机 3.3V
```

方案 B（保留 5V 电机轨）：保留 U8，但必须换成 ≥3A 的升压（如 TPS61088），并按第 3 节修正接法；电机 VM 接 +5V。

> 选 A 还是 B，取决于你的步进电机额定电压/线圈电阻，见第 5 节。

---

## 2. 致命问题 1：两个 DC-DC 的 VIN/VOUT 接反

TI 的 DSK/DRC 封装标准引脚：`1=VOUT, 2=L2, 3=PGND, 4=L1, 5=VIN, 6=EN, 7=PS/SYNC, 8=VINA, 9=GND, 10=FB`。

网表现状（U7）：

```
+3.3V  ← U7-5  VIN      ← 输入接在自己的输出轨上
+3.3V  ← U7-10 FB       ← 这个是对的
$1N206 ← U7-1  VOUT     ← 输出只接了 EN/PS/SYNC 和 C3
$1N206 ← U7-6  EN
$1N206 ← U7-7  PS/SYNC
```

后果：

1. **+3.3V 网络上只有输入脚**（U1-2、U7-5、U7-10、U3-1、C14/C15），没有任何功率源 → 3.3V 浮空；
2. EN 接在自己的 VOUT 上 → 没输出就永远没 EN → **自锁，永不启动**；
3. 真正的输出脚上只有 0.1µF，10µF 全在"输入端"，环路不稳定。

U8 同样错误（`VIN=+5V`、`VOUT→EN/PS`、`FB=+5V`），只是多了 R6(100Ω) 到 VCC 的一条路，所以它"看起来"能启动一点点——这个不对称本身就说明是画错了。

### 修正表：U7（TPS63031，3.3V）

| 引脚 | 现在接到 | 改成 |
|---|---|---|
| 1 VOUT | `$1N206`（EN/PS/C3） | **+3.3V** |
| 5 VIN | +3.3V | **VCC（电池）** |
| 6 EN | `$1N206` | **VCC**（常开；若要开关机，改成经电源开关到 VCC） |
| 7 PS/SYNC | `$1N206` | **GND**（省电模式；想要低纹波可接 VCC 强制 PWM） |
| 8 VINA | VCC | VCC（不变） |
| 10 FB | +3.3V | +3.3V（不变） |
| 2 L2 / 4 L1 | L2 | 不变 |
| 3 PGND / 9 GND / 11 EP | PGND / GND | 不变 |
| C3 0.1µF | 在 `$1N206` | 移到 **+3.3V**，并且**再加 10µF 陶瓷**贴在 VOUT 脚旁 |

### 修正表：U8（TPS63002，5V）——仅在采用方案 B 时保留

| 引脚 | 现在接到 | 改成 |
|---|---|---|
| 1 VOUT | `$1N221` | **+5V** |
| 5 VIN | +5V | **VCC** |
| 6 EN | `$1N221` | **VCC** |
| 7 PS/SYNC | `$1N221` | **GND** |
| 10 FB | +5V | +5V（不变） |
| 8 VINA | VCC | VCC（不变） |
| R6 100Ω | `$1N221` ↔ VCC | **删除**（这是 EN 自锁的旁路，正解是 EN 直接接 VCC） |
| C11 0.1µF | 在 `$1N221` | 移到 **+5V**，再加 10µF |

> 自查方法：改完后点"设计规则/DRC"里的"单网络"提示，应该只有 GND/PGND 这类允许的；`$1N206`、`$1N221` 这两个自动命名网络应该消失。

---

## 3. 致命问题 2：D1 反接

网表：`+5V → D1-1(A)`，`USB VBUS → D1-2(K)`。电流方向是"板子 → USB 口"。

- 插 USB：VBUS 被挡住，板子拿不到电；
- 若 5V 修好：电池电压会倒灌进电脑 USB 口。

**改成**：`D1-A ← VBUS`，`D1-K → +5V`。
另外 VBUS 上现在是**零电容**，加 10µF + 100nF。

---

## 4. 严重问题：电机 IO 撞 PSRAM

ESP32-S3-WROOM-1-**N16R8** 是 **8MB 八线（octal）PSRAM**，模块内部占用 **GPIO33~GPIO37**。你现在的电机信号：

```
IO35 / IO36 / IO37 → U2 的 AIN1/AIN2/BIN1
```

这三个脚被模块内部 PSRAM 占用，外接信号会直接影响 PSRAM 初始化，轻则 PSRAM 不可用，重则启动异常。

### 修正：电机信号重映射

相机已占 IO4~IO18，USB 占 IO19/IO20，所以可用脚为：`IO1, IO2, IO21, IO38, IO43, IO44, IO47, IO48`（正好 8 个，留给两个步进）。

| 信号 | 现在 | 改成 |
|---|---|---|
| U2-AIN1（电机1 A 相） | IO35 | **IO1** |
| U2-AIN2 | IO36 | **IO2** |
| U2-BIN1（电机1 B 相） | IO37 | **IO21** |
| U2-BIN2 | IO38 | **IO38**（不变） |
| U5-AIN1（电机2 A 相） | IO39 | **IO43** |
| U5-AIN2 | IO40 | **IO44** |
| U5-BIN1（电机2 B 相） | IO41 | **IO47** |
| U5-BIN2 | IO42 | **IO48** |

说明：

- IO43/IO44 是 UART0（TXD0/RXD0）。你用的是原生 USB（IO19/20），串口调试走 USB-CDC，所以这两脚空闲；如果以后想用引脚串口，改用 IO39~IO42（代价是失去外部 JTAG，USB-JTAG 仍可用）。
- IO45/IO46/IO0/IO3 是 strapping 脚，不要拿来做电机信号。
- IO35/36/37 之后**彻底不要用**（除非换 N16R2/N8R2 这类四线 PSRAM 的模块）。

## 5. 严重问题：电机供电与驱动选型

### 5.1 供电能力

现状：`U2-3 VM` 和 `U5-3 VM` 都接 **+5V**，而 +5V 由 TPS63002 从 1S 电池升上来，**额定 1.8A**。

两个双极步进，每相 0.5A 时总电流就是 2A；堵转/加速更高。**1.8A 不够**，5V 会塌陷，MCU 可能复位。

**修正（方案 A）**：把 `U2-3`、`U5-3` 从 +5V 改接 **VCC（电池）**，并把每个驱动器的 VM 去耦补齐：

```
每个 U2/U5 的 VM 旁：100µF 电解 + 10µF 陶瓷 + 100nF 陶瓷
```

LY2834E 的 VM 支持 2~15V，直接吃 1S 电池（3.0~4.2V）合法。

### 5.2 LY2834E 的本质局限（重要）

它是**双 H 桥 + IN/IN 直控**，**没有电流斩波、没有 STEP/DIR、没有微步**。这意味着：

- 线圈电流 = 电压 / 线圈电阻（稳态），**不是恒流**；
- 供电电压越高、线圈电阻越小，电流越大，超过 1A 就触发 OCP；
- 静止保持时线圈一直通直流，**发热大、耗电快**；
- 想做微步只能在固件里对 IN 脚做 PWM，效果差、噪声大、低速抖动明显。

**按你的电机选供电：**

| 步进规格 | 线圈电阻 | 建议供电 | 说明 |
|---|---|---|---|
| 5V / 0.5A | ≈10Ω | VCC（3.7V） | 电流约 0.37A，扭矩降约 30~40%，最安全 |
| 5V / 0.5A | 5~8Ω | 5V（方案 B） | 0.6~1A，接近 OCP，注意散热 |
| 5V / 1A | <5Ω | **不能直接接 5V** | 会超 1A，必须换恒流驱动 |
| 12V 规格 | — | 5V 只有部分扭矩 | 建议 2S + 降压，或换驱动 |

**如果这是相机云台/需要平滑低速**：建议换 **TMC2209**（STEP/DIR + UART，2 个 GPIO/电机，静音、微步、恒流）或 **A4988/DRV8825**。这样还能省下 4 个 GPIO。

如果只是学习"让步进转起来"，LY2834E 可用，但把每相电流控制在 **0.4~0.5A** 以内，并把 EP 焊到大铜箔上散热（900mΩ × 2 管 × 0.5A² ≈ 0.45W/桥，双桥约 0.9W/片）。

### 5.3 电感

`L1/L2` 是 **0603 封装**。TPS63031 输出 0.9A 时电感峰值约 1.5A，TPS63002 输出 1.8A 时峰值 3A+。0603 电感饱和电流通常只有 1~1.5A → 饱和、效率崩、发热。

换 **4020 或 5020 屏蔽电感，饱和电流 ≥3A**（1.5µH / 2.2µH 保持）。

---

## 6. 严重问题：充电器与电机抢 5V

TP4054 的 VIN 接在 +5V，而 +5V 同时又是 D1 的输出和（方案 B 的）电机轨。

- 插 USB 时，充电电流（现设 500mA）+ 系统电流会超过 USB 默认 500mA 预算；
- 若电机也从 +5V 取电，电流会经 D1（1A）反向灌进 USB 口。

**修正**：

- 方案 A 下电机改接 VCC，这个问题自动消失（5V 只剩充电器）；
- 充电电流改小：`R8` 从 2k 改 **3.3k（≈300mA）** 或 **4.7k（≈210mA）**。原因是 TP4054 是 SOT-23-5 线性充电，500mA 时 (5-3.7)×0.5 ≈ 0.65W，结温升约 160℃，会反复进热调节；
- 更好的做法是加**电源路径管理**（如 IP5306、TP5400 这类带 path 的芯片），插 USB 时系统直接由 USB 供电、电池独立充电。

## 7. 中等问题清单

| # | 位置 | 问题 | 修法 |
|---|---|---|---|
| 1 | U1-3 EN | 只有 R5 10k 上拉，无电容、无按键 | 加 **1µF 到 GND** + RESET 按键（EN→按键→GND） |
| 2 | U1-27 IO0 | 只接 Q1 基极，无上拉、无 BOOT 键 | **10k 上拉到 3.3V** + BOOT 按键（IO0→按键→GND） |
| 3 | Q1 | 射极接的 `OUTP` 是死网络（全表只有一个脚） | **删除 Q1 和 OUTP**（这段电路没有任何作用） |
| 4 | USB1 | 只接了 A6/A7，**B6/B7 悬空** | 把 **A6-B6、A7-B7 短接**，否则 Type-C 反插不识别 |
| 5 | USB1 D+/D- | 无 ESD 保护 | 加 **USBLC6-2SC6** |
| 6 | VBUS | 无去耦 | 10µF + 100nF |
| 7 | 相机 U3 | SIOD/SIOC 无外部上拉；3.3V 无就近去耦 | 2.2k 上拉到 3.3V；10µF + 100nF 贴模块 |
| 8 | 电池 H1 | 无过放保护、无反接保护 | 加 **DW01A + FS8205A**（1S 保护）或 PMOS 反接保护 |
| 9 | H1 端子 | 2.54 排针额定 3A | 步进小电流够用；若每相 1A，建议换 XT30 或焊线 |
| 10 | 全板 | 无 3.3V/5V 测试点、无电源指示灯 | 加测试点 + 一颗电源 LED（1k 限流） |
| 11 | IO45/IO46 | strapping 脚悬空 | 内部有下拉，一般可以；建议留 10k 下拉 + 测试点 |

## 8. 建议的修改顺序（分三步验证）

### 第一步：先让板子点亮（只改电源）

1. U7：VIN→VCC、VOUT→+3.3V、EN→VCC、PS→GND、FB→+3.3V，输出加 10µF；
2. D1 方向翻转，VBUS 加 10µF+100nF；
3. 删掉 U8 和 R6（方案 A），或按第 2 节修正（方案 B）；
4. 上电只测：+3.3V 是否 3.3V、EN 是否高、MCU 是否能被 USB 识别。
   **这一步不要接电机和相机。**

### 第二步：让步进转起来

1. 电机信号按第 4 节重映射，挪出 IO35~IO37；
2. VM 改接 VCC，补 100µF+10µF+100nF；
3. 固件里先写一个纯软件的四拍序列（A+ → B+ → A- → B-），频率 100~500Hz，先不接相机；
4. 测每相电流，确认 ≤0.5A。

### 第三步：上相机和无线

1. 相机 3.3V 就近去耦 + I2C 上拉；
2. 确认 WiFi 发射时 3.3V 不掉压（示波器看 MCU 3V3 脚）；
3. 最后再做外壳/走线优化。

## 9. 待你确认的参数

| 参数 | 为什么需要 |
|---|---|
| 步进电机型号、额定电压/电流、每相电阻 | 决定供电电压和是否需要换驱动（第 5 节） |
| 电池容量、是否 1S | 决定续航和升压选型 |
| 是否需要 5V 轨（除充电外还有 5V 器件吗） | 决定删不删 U8 |

| 这板子最终用途（云台 / 小车 / 机械臂） | 决定要不要微步、要不要限位开关输入 |

## 10. 附：修正后的引脚映射（供固件用）

```c
// 两个双极步进，IN/IN 直控（LY2834E）
#define PIN_M1_A1  1    // U2-AIN1  → 电机1 A 相
#define PIN_M1_A2  2    // U2-AIN2
#define PIN_M1_B1  21   // U2-BIN1  → 电机1 B 相
#define PIN_M1_B2  38   // U2-BIN2
#define PIN_M2_A1  43   // U5-AIN1  → 电机2 A 相
#define PIN_M2_A2  44   // U5-AIN2
#define PIN_M2_B1  47   // U5-BIN1  → 电机2 B 相
#define PIN_M2_B2  48   // U5-BIN2
#define PIN_I2C_SDA 12  // 注意：现被相机 SIOD 占用，若加 IMU 需另选
#define PIN_I2C_SCL 13
```

> 注意：`IO12/IO13` 现在被相机的 SIOD/HREF 占用。如果以后要加 IMU（I2C），需要从相机信号里腾出两脚，或改用 SPI 并重新分配。
